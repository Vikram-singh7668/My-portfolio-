# Vikram | Full Stack Developer Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript. No frameworks or build tools needed.

## Features

- Interactive hero ballot: visitors "cast a vote" and are taken to the contact section or the project
- Light and dark themes (follows system setting, with a manual toggle that remembers the choice)
- Project showcase for the E-Voting System with an animated sample tally
- Skills, experience, education, certifications and achievements
- Contact form with validation that opens the visitor's email app
- Fully responsive, with a mobile menu
- Keyboard accessible, with visible focus and reduced-motion support

## Project structure

portfolio/

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

That's it. The page loads two Google Fonts (Bricolage Grotesque and Hanken Grotesk), so it needs internet for the intended look. It falls back to system fonts offline.

## Deploy for free

**GitHub Pages**
1. Push the files to a GitHub repository.
2. Go to Settings → Pages.
3. Under Source, choose the `main` branch and the `/ (root)` folder, then save.
4. Your site will be live at `https://<username>.github.io/<repository>/`.

**Netlify or Vercel**
Drag and drop the project folder into the dashboard, or connect the repository.

## Customize

- **Content:** edit the text in `index.html`.
- **Colors:** change the variables at the top of `style.css` (`--ink`, `--paper` and so on).
- **Contact email:** update the `TO` constant in `script.js` and the `mailto:` links in `index.html`.

## Tech used

HTML5, CSS3 (custom properties, grid, flexbox), JavaScript (ES6+)
